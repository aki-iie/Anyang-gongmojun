# 잠길까 — 안양시 반지하 침수 위험 진단

2026 안양시 공공데이터·AI 활용 대학생 경진대회 출품작.
반지하 거주자가 **집 사진 3장과 위치**를 넣으면, AI가 구조적 취약 요인을 묻고 **안양시 도시침수지도**와 결합해 침수 위험도를 점수로 내는 웹 서비스.

## 1. 사용자가 겪는 흐름

**모바일** (실제 사용자 기준)

```
1단계 · 우리 집 위치      주소 검색 또는 현재 위치 → 지도로 확인
2단계 · 사진 3장          현관 턱 → 창문 → 골목 (카메라 바로 실행)
3단계 · 문진              AI가 사진을 보고 애매한 부분만 되물음
4단계 · 결과              총점 + 침수지도 오버레이 + 대비책 + 후속 대화
```

**데스크톱**은 1·2단계가 한 화면에 함께 나온다.

### 지도는 두 번 나오고, 역할이 다르다

- **1단계** — 배경지도 + 핀만. *"여기가 우리 집이 맞나요?"* 를 확인하는 화면이라 침수 구역을 덮지 않는다.
- **4단계** — 같은 지도에 침수 레이어가 얕은 등급부터 차례로 차오르고, 핀 위에 `N334 · +30점` 배지가 새겨진다.

## 2. 점수는 이렇게 나온다

총 100점 만점. **침수지도(지역) + 구조 요인(가구)** 의 합이다.

| 항목 | 배점 | 출처 |
|---|---|---|
| 도시침수지도 예상 침수심 | 0~30 | 실제 좌표 판정 |
| 현관 턱 높이 | 0~30 | 사진 + 문진 |
| 창문 아래쪽 높이 | 0~20 | 사진 + 문진 |
| 골목 침수 이력 (2022.8 앵커) | 0~15 | 문진 |

**50점 이상**이면 안양시 설치 지원 대상, **70점 이상**은 "매우 높음".

> **사진만으로 침수 정도는 판단할 수 없다.** 사진은 *"물이 들어오기 쉬운 구조인가"* 를 답하고, 침수지도는 *"이 자리에 물이 얼마나 차는가"* 를 답한다. 사진 한 장에는 주변 지형 고저차도, 하수관 용량도 담기지 않는다. 그래서 둘 다 필요하다.

## 4. 개발과 배포

```bash
npm install          # 최초 1회
npm run dev          # 로컬 개발 서버 (저장하면 즉시 반영)
npm run lint         # 코드 점검 — 현재 오류 0 · 경고 0
npm run build        # dist/ 생성 (tsc + vite)
```

### 배포

```bash
# src/ 를 고쳤으면
npm run build && firebase deploy --only hosting

# functions/ 를 고쳤으면
firebase deploy --only functions
```

**로컬(`npm run dev`)에서는 `/api/*` 가 없다.** 침수 판정·주소 검색·AI는 배포본에서만 동작한다. 화면 문구나 레이아웃만 볼 때는 로컬이 빠르다.

**배포 후 화면이 안 바뀌면** `index.html` 캐시다. 주소 뒤에 `?v=2` 를 붙이거나 강력 새로고침하면 된다.

## 5. 기술 구성

### 스택
Vite 8 · React 19 · TypeScript · Leaflet · Firebase(Hosting + Cloud Functions Node 22)
CSS 프레임워크 없이 인라인 스타일 헬퍼 `css()` 사용. 서체 Noto Serif KR.

### AI
**gpt-4o-mini** (OpenRouter 경유). 호출 3종:

| 용도 | 설정 |
|---|---|
| 사진 분석 (Vision) | temp 0.2, JSON 모드 |
| 자유 텍스트 → 보기 매핑 | temp 0, JSON 모드 (로컬 매칭 실패 시에만) |
| 자유 대화 | temp 0.7 |

**실측 비용 — 진단 1회 약 $0.0066 (9원).** prompt 토큰 42,000개 중 대부분이 사진이다. 업로드 시 긴 변 1024px로 줄이면 비용·속도가 크게 개선된다(미적용).

AI 응답은 `normalizeVLM()` 을 반드시 통과한다. 보기가 비었거나 형태가 어긋나면 `content.ts` 기본값으로 폴백하므로 **문진이 멈추지 않는다.**

### 문진이 막히지 않는 세 경로
버튼 클릭 · 자유 텍스트 · 건너뛰기 모두 `commitAnswer()` 하나로 모인다.
자유 텍스트는 로컬 매칭 → 실패 시 AI 매핑. 그래도 안 되면 선택지를 다시 띄운다.
되묻는 질문("차수판이 뭐예요?")은 답한 뒤 원래 질문으로 돌아온다.

### 키 보안
- **클라이언트**: `getApiKey()` 가 `import.meta.env.DEV` 로 게이트되어, 배포 빌드에서는 `() => null` 로 상수 폴딩된다. **번들에 AI 키가 들어가지 않는다** (매 배포마다 확인).
- **배포본**은 `/api/llm` 프록시를 탄다. 서버 키는 `functions/.env`.
- **프록시 가드레일**: 모델 화이트리스트(gpt-4o-mini만) · origin 검사 · 메시지 40개 상한 · max_tokens 1200. 외부 origin 403, 허용 외 모델 400으로 검증됨.
- VWorld 키는 지도 타일용이라 클라이언트에 노출된다(지도 API 표준 관행).

## 6. 침수지도 연동

원본: 국가공간정보 **도시침수지도 30년·50년 빈도** SHP — 만안구(41171)·동안구(41173).
좌표계 **EPSG:5186**(KGD2002 중부원점) → WGS84 변환 후 `functions/flood*.json` 에 적재.

- 속성 `SEG_CODE` **N330~N334** 가 침수심 등급. **숫자가 클수록 깊다** — 면적(N330 8.35km² → N334 0.001km²)과 폴리곤 포함관계로 확인.
- **각 등급의 실제 m 구간은 아직 확정되지 않았다.** 현재 배점(30/28/25/20/12)은 순서만 반영한 잠정값. 원본 배포처 범례를 확인하면 `functions/flood.js` 의 `LEVEL` 표 한 곳만 고치면 화면·점수·지도가 모두 따라온다.
- 판정은 **서버에서만** 한다. 지도 데이터 2.5MB는 브라우저로 내려가지 않는다. 판정 200회 7ms.
- 30년·50년을 각각 판정해 **보수적인 쪽(50년)** 을 점수로 쓰고, 두 빈도를 화면에 함께 보여준다.

**검증** — 충훈동 좌표가 "침수 예상 구역 아님"으로 나온다. 기획서의 *"충훈동은 침수흔적도상 이력은 있으나 도시침수지도상 위험 지역이 아니다"* 와 일치한다.

**침수 면적 비교** (단위 km², 만안+동안 합계)

| 등급 | 30년 | 50년 | 증가 |
|---|---|---|---|
| N330 | 8.353 | 8.608 | +3.1% |
| N331 | 0.465 | 0.517 | +11.2% |
| N332 | 0.085 | 0.097 | +13.5% |

깊은 등급일수록 증가폭이 크다 — 비가 더 오면 넓어지기보다 **깊어진다.**

## 7. 위치 입력 세 가지

| 방법 | 키 | 비고 |
|---|---|---|
| **주소 검색** | 불필요 | 다음(카카오) 우편번호 → VWorld 지오코더로 좌표 변환 |
| **현재 위치** | 불필요 | 브라우저 Geolocation. 집에서 접속하면 가장 정확 |
| **URL 좌표** | 불필요 | `?lat=&lon=&acc=` — 현장에 가지 않고 시연·테스트 |

위치가 거부되면 **기기별(iPhone/Android/PC) 위치 켜는 법**이 화면에 단계별로 뜬다. 코드로 권한 팝업을 강제할 수는 없다(브라우저 보안 정책).

### 시연용 링크

```
가장 깊은 구간 (N334 · +30점)
https://jamgilkka.web.app/?lat=37.39908&lon=126.93219

30년 안전 → 50년 침수 (빈도 차이가 드러나는 자리)
https://jamgilkka.web.app/?lat=37.38428&lon=126.90114

충훈동 — 구역 밖 (기획서 검증 지점)
https://jamgilkka.web.app/?lat=37.3985&lon=126.9130
```

## 8. 서버 엔드포인트

| 경로 | 리전 | 하는 일 |
|---|---|---|
| `POST /api/llm` | us-central1 | AI 프록시. 키를 서버에서 붙여 대신 호출 |
| `GET /api/flood?lat=&lon=` | us-central1 | 침수 판정. `&shape=1` 이면 주변 폴리곤도 반환 |
| `GET /api/geocode?address=` | **asia-northeast3** | 주소 → 좌표 |

> `geocode` 만 서울 리전인 이유 — **VWorld 지오코더가 해외 IP 연결을 끊는다**(`UND_ERR_SOCKET`). 국내 리전에서만 응답한다.

## 10. 저장소 규칙

- `.env`, `functions/.env` 는 **절대 커밋하지 않는다** (`.gitignore` 등록됨)
- `functions/flood*.json` 은 변환 결과물이다. 원본 SHP에서 다시 만들 수 있지만 직접 편집하지 말 것
- 커밋 전 `npm run lint` 로 확인 — 현재 **오류 0 · 경고 0**
