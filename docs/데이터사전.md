## 먼저 — `inflowCm` 이 뭐냐

**`inflowCm` = 예상 침수심 − 실효 방어높이 (cm)**

> 이 집의 가장 낮은 개구부보다 물이 **몇 cm 더 높이** 차오르는가

```
inflowCm = depthCm − defenseCm      (단, 양수일 때만. 방어되면 0)
```

예시 — 현관 턱 없음(0cm) + 물막이판 미설치, 예상 침수심 33cm:

```
defenseCm = 0        실효 방어높이 (현관과 창문 중 낮은 쪽)
depthCm   = 33       그 지점 예상 침수심
inflowCm  = 33       → 현관으로 33cm 가 넘어 들어온다
```

**읽는 법**

| 값 | 뜻 |
|---|---|
| `null` | 판정 보류. 침수심을 못 구했거나 개구부를 확인 못 함 |
| `0` | 방어됨. 물이 방어높이를 못 넘는다 |
| `양수` | **그만큼 물이 들어온다. 클수록 급하다** ← 공무원 콘솔 정렬 키 |

점수가 아니라 **cm** 다. 73점이 아니라 33cm. 단위가 실물이라 "이 집은 33cm 물막이가
필요하다" 로 바로 이어진다. 통합 점수를 만들지 않은 이유가 이것이다.

⚠ 혼동 주의 — 비슷한 이름 네 개

| 필드 | 뜻 |
|---|---|
| `depthCm` | 그 **지점**의 예상 침수심 (지도에서 온 값) |
| `defenseCm` | 그 **집**의 실효 방어높이 (문진에서 계산) |
| `inflowCm` | 둘의 차이 — **들어오는 양** |
| `needBarrierCm` | 필요한 차수 설비 높이 = `depthCm` (행안부 고시 제23조: 예상 침수 높이 이상 확보) |

## 3. 계산된 필드 — 어떻게 나오는가

### 경로 A (지표 유입)

```
현관 방어높이 = SILL_CM[entrance_sill] + (water_panel=='설치' ? 30 : 0)
창문 방어높이 = WINDOW_BASE_CM[window_base] + (window_barrier=='설치' ? 30 : 0)

defenseCm     = min(현관, 창문)        ← 가장 낮은 개구부가 정한다
weakestPoint  = 그 낮은 쪽 이름         '현관' 또는 '창문'
inflowCm      = depthCm − defenseCm     (음수면 0)
needBarrierCm = depthCm
```

| `surfaceStatus` | 조건 |
|---|---|
| `유입가능` | `depthCm > defenseCm` |
| `방어가능` | 두 개구부를 **다 알고** `depthCm ≤ defenseCm` |
| `확인필요` | 개구부를 모르거나 침수심을 못 구함 |

★ **비대칭 원칙**: 아는 개구부만으로 이미 유입이 확정되면 모르는 쪽과 무관하게 `유입가능`.
반대로 아는 쪽이 방어돼도 모르는 개구부가 있으면 `방어가능` 이 아니라 `확인필요`.
"위험하다"는 한쪽만 알아도 말할 수 있지만 "안전하다"는 전부 알아야 말할 수 있다.

### 경로 B (역류)

신호를 센다. 확률을 계산하지 않는다.

| `backflowStatus` | 조건 |
|---|---|
| `매우미흡` | `floor_backup='있음'` **또는** 신호 3개 이상 |
| `미흡` | 신호 1개 이상 |
| `확인필요` | 핵심 4슬롯이 전부 unknown |
| `양호` | 그 외 |

`signalCount` = 신호 개수, `signals` = 신호 문장 배열, `experienced` = 역류 경험 여부.

### `level` — 서버가 파생 (`functions/save.js`)

| `level` | 조건 |
|---|---|
| `위험` | `surfaceStatus='유입가능'` 또는 `backflowStatus='매우미흡'` |
| `주의` | `backflowStatus='미흡'` |
| `확인필요` | 둘 중 하나가 `확인필요` |
| `안전` | 그 외 |

**클라이언트가 보낸 `level` 은 받지 않는다.** 서버가 두 경로 판정에서 직접 계산한다.

## 4. 침수심 필드 — 어디서 온 값인가

| 필드 | 뜻 |
|---|---|
| `flood.predCm` | 채널 A — 도시침수지도 **예측** (30·50년 빈도) |

## 6. 두 컬렉션 차이

| | `diagnoses` | `stats` |
|---|---|---|
| 언제 | **동의한 경우만** | **모든 진단** |
| 주소 | 전체 주소 + 상세주소 | ❌ 없음 |
| 좌표 | `lat` / `lon` | ❌ 100m 격자로 대체 |
| 12슬롯 | ✅ | ✅ |
| 판정 결과 | ✅ 전체 | ✅ 요약만 |
| 읽기 권한 | admin 커스텀 클레임 | admin 커스텀 클레임 |

나눈 기준은 **위험도가 아니라 동의**다. 안전하게 나온 집도 `stats` 에 남겨야
"안양 반지하 중 몇 %" 의 분모가 생긴다.
